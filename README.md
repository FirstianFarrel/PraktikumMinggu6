1. Jelaskan secara singkat apa itu JavaScript dan kegunaannya!
JavaScript adalah bahasa pemrograman high-level, scripting, dan bersifat client-side yang berjalan di dalam browser web.

Kegunaan: Digunakan untuk membuat halaman web menjadi interaktif dan dinamis, seperti merespons aksi penggunan (click, hover, input), mengolah data form, memanipulasi elemen HTML/CSS (DOM manipulation), serta melakukan komunikasi data asynchronous (AJAX) tanpa perlu memuat ulang halaman (reload).
2. Jelaskan secara singkat apa itu jQuery dan kegunaannya!
jQuery adalah pustaka (library) JavaScript yang cepat, kecil, dan kaya fitur yang dirancang untuk menyederhanakan penulisan kode JavaScript (dengan prinsip "Write Less, Do More").

Kegunaan: Digunakan untuk mempermudah manipulasi dokumen HTML (DOM), penanganan event (event handling), animasi/efek visual, dan pemanggilan AJAX agar kodenya lebih singkat serta kompatibel di berbagai browser
3. Perbedaan JavaScript dan jQuery
JavaScript merupakan bahasa pemrograman native (*vanilla*) yang dapat berjalan langsung di *browser* dengan performa eksekusi lebih cepat. Sementara itu, jQuery adalah *library* berbasis JavaScript yang membutuhkan file pustaka tambahan, namun menawarkan sintaksis yang jauh lebih singkat dan ringkas untuk menyederhanakan manipulasi DOM serta penanganan *event*[cite: 1].
